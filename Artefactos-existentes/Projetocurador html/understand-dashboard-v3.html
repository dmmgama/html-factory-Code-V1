DADOS

O que persiste

Vive em localStorage (3 chaves). O objeto STATE em memória é a cópia viva.

  • STATE.projetos[] — 44 projetos
  • STATE.links[] — 30 relações seed
  • STATE.domains[] — 6 domínios
  • STATE.domainTree — hierarquia V3
  • UI — filtros, colunas, sort
MOTOR

Calcula, não desenha

Funções puras (ou quase puras) que recebem STATE e devolvem dados computados.

  • passesFilter(p) → boolean
  • filtered() → projetos visíveis
  • sortRows() → ordenados
  • computeGroups() → componentes grafo
  • domTree(), domParent()…
VIEWER

Desenha, não guarda

Funções render*() que reescrevem o DOM do zero em cada chamada.

  • renderAll() — coordenador
  • renderBody() — linhas da tabela
  • renderGraph() — SVG de ligações
  • renderAtribuicoes() — drag-drop
  • renderSubdomView() — V3 drill-down
